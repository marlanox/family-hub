# Family Hub

Наша семья — общие задачи, баллы, награды и напоминания. Mobile-first PWA,
без ролей «админ/участник» — у всех одинаковые права. Подробности
архитектуры: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000 — приложение сразу работает с демо-данными
(Маша, Наташа, Ваня) и ничего дополнительно настраивать не нужно: все
данные хранятся прямо в браузере (localStorage), офлайн и бесплатно.

## Установка как приложение (PWA)

1. Задеплойте проект (см. ниже) или откройте `npm run build && npm run start`
   на телефоне в той же сети.
2. В Safari (iPhone): «Поделиться» → «На экран «Домой»».
   В Chrome (Android): меню → «Установить приложение» / «Добавить на
   главный экран».
3. Готово — иконка на рабочем столе, открывается как обычное приложение,
   работает офлайн.

**Важно про хранение данных.** По умолчанию у каждого члена семьи данные
хранятся отдельно на его телефоне — баллы и задачи не синхронизируются
между устройствами, пока не подключите Supabase (ниже). Это осознанный
выбор: так приложение работает сразу, бесплатно и без сервера, которым
нужно управлять.

## Деплой бесплатно

Вариант без каких-либо затрат: [Vercel](https://vercel.com) (free tier) —
подключаете GitHub-репозиторий, деплой автоматический при каждом push,
собственный HTTPS-домен из коробки (обязателен для PWA/уведомлений).

## Синхронизация между телефонами всей семьи (опционально)

Чтобы баллы и задачи видели все на своих устройствах, нужен общий "облачный"
источник данных — без этого никак, но он не обязан быть платным сервером,
которым управляете вы. Бесплатный уровень [Supabase](https://supabase.com)
(Postgres + Auth + Storage + Realtime) полностью бесплатен для проекта
такого размера, без карты.

1. Создайте проект на supabase.com (бесплатно).
2. В SQL Editor выполните `supabase/schema.sql` — это создаст таблицы и
   политики доступа (у всех членов семьи одинаковые права на данные своей
   семьи, ролей нет).
3. Скопируйте `Project URL` и `anon public key` из настроек проекта.
4. Создайте файл `.env.local`:
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=xxxxxxxxxxxxxxxx
   ```
5. Пересоберите и задеплойте — `src/lib/supabaseClient.ts` подхватит эти
   переменные автоматически.

Без этих переменных приложение продолжает работать локально — ничего не
ломается, синхронизация просто выключена.
